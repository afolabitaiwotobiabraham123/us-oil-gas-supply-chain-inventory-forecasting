# MySQL Analysis

This folder contains SQL scripts used to store, query, analyze, and evaluate materials, inventory, procurement, and supplier data for the Canadian Natural Resources project.

## Planned SQL Scripts

1. `01_database_setup.sql` — Create the database and required tables.
2. `02_materials_analysis.sql` — Analyze material categories, consumption patterns, and material usage.
3. `03_inventory_analysis.sql` — Analyze inventory balances, stock movements, shortages, and excess inventory.
4. `04_inventory_kpi_calculations.sql` — Calculate inventory performance indicators, including turnover, days of inventory on hand, and stockout rate where data permits.
5. `05_procurement_supplier_analysis.sql` — Analyze purchase orders, supplier performance, and replenishment lead times where data is available.

## Tools

- MySQL

SQL analysis will focus on structured queries, inventory performance measurement, material consumption, procurement analysis, and business insights.
