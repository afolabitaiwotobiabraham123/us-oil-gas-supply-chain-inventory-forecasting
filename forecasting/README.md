# Petroleum Inventory Forecasting

This folder contains the time-series analysis and forecasting activities for predicting future US petroleum inventory levels using historical EIA data.

## Forecasting Objectives

- Analyse historical petroleum inventory patterns.
- Identify inventory trends and seasonal variations.
- Examine historical inventory fluctuations.
- Forecast future petroleum inventory levels.
- Evaluate forecasting model performance.
- Generate insights to support inventory planning.

## Notebook

`05_petroleum_inventory_forecasting.ipynb`

## Forecasting Workflow

1. Load processed petroleum inventory data.
2. Prepare historical time-series data.
3. Analyse trends and seasonality.
4. Select appropriate forecasting methods.
5. Train forecasting models.
6. Generate future inventory predictions.
7. Evaluate forecast accuracy.
8. Visualize actual and forecast inventory levels.

## Tools and Libraries

- Python
- Pandas
- Matplotlib
- Statsmodels
- Scikit-learn

**Note:** Forecasting will use actual historical EIA inventory data. Forecast results will be treated as analytical estimates, not official EIA predictions.
