# Python Data Analysis

This folder contains Jupyter Notebooks used for petroleum data acquisition, exploration, quality assessment and preparation.

## Notebooks

| Notebook | Purpose |
|---|---|
| 01_data_acquisition.ipynb | Obtain petroleum datasets from the EIA. |
| 02_exploratory_data_analysis.ipynb | Explore inventory, supply, demand, imports and exports. |
| 03_data_quality_assessment.ipynb | Assess data completeness, accuracy, consistency and reliability. |
| 04_data_cleaning_preparation.ipynb | Clean, transform and prepare datasets for further analysis. |

## Tools and Libraries

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Requests

## Workflow

1. Acquire original EIA datasets.
2. Explore the datasets and understand their structure.
3. Assess data quality before cleaning.
4. Clean and prepare the datasets.
5. Export processed datasets to `data/processed/`.

**Note:** All Python data acquisition and preparation activities will be documented in their respective notebooks.
