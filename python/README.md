# Python Analysis

This folder contains the Python and Jupyter Notebook workflows used to acquire, explore, assess, clean, and prepare materials and inventory datasets for the Canadian Natural Resources project.

## Planned Notebooks

1. `01_data_acquisition.ipynb` — Collect or load publicly accessible and simulated materials and inventory datasets.
2. `02_exploratory_data_analysis.ipynb` — Explore material consumption, inventory transactions, stock movements, and procurement patterns.
3. `03_data_quality_assessment.ipynb` — Assess missing values, duplicate records, inconsistencies, and data validity.
4. `04_data_cleaning_and_preparation.ipynb` — Clean, transform, and prepare datasets for SQL analysis, forecasting, and visualization.

## Tools

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Requests, where API data acquisition is required.

The notebooks will document each stage of the data preparation and analysis workflow.
